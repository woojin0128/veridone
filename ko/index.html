자주 묻는 질문

Claude가 느려지나요?

훅 하나당 약 60ms입니다. 출력 압축으로 아끼는 컨텍스트가 보통 플러그인이 차지하는 양(상시 약 1,000토큰, 대부분 에이전트 설명)보다 큽니다.

오탐은 없나요?

규칙은 정밀도 위주로 조정돼 있고, 이번 수정이 추가한 줄만 봅니다. 한 줄은 veridone-allow: <규칙> <이유> 주석으로, 규칙 하나는 .claude/veridone.json으로, 전체는 /veridone:mode relaxed로 조정할 수 있습니다.

Claude에게 쓸데없는 일을 시키지 않나요?

완료 게이트는 한 턴에 최대 한 번만 되돌려 보내고, “~ 때문에 테스트를 돌리지 못했습니다” 같은 솔직한 설명이면 통과합니다.

Claude가 그냥 꺼버릴 수 있나요?

몰래는 안 됩니다. 모드를 낮추거나 Veridone 설정, Claude 설정, git 훅을 바꾸거나 플러그인을 끄려면 사용자 확인이 필요합니다. Team 플랜의 잠금 조직 정책은 프로젝트 쪽에서 덮어쓸 수 없습니다.

코드가 밖으로 나가나요?

아니요. 텔레메트리를 보내지 않고, 훅과 MCP 서버는 네트워크 요청을 하지 않습니다. 유일한 네트워크 통신은 유료 키의 라이선스 확인(활성화할 때와 며칠마다 백그라운드)이며, 키와 무작위 컴퓨터 이름만 보내고 코드에 관한 정보는 보내지 않습니다.

보안 샌드박스인가요?

아닙니다. 협조적인 에이전트의 실수와 지름길을 막는 장치입니다. 신뢰할 수 없는 에이전트를 가두려면 Claude Code의 샌드박스와 권한 설정을 쓰세요.

다른 에이전트에서도 되나요?

CLI 검사와 GitHub Action은 어떤 도구와도 쓸 수 있습니다. 훅은 Claude Code 전용입니다.
