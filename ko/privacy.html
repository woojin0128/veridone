플러그인

Veridone은 사용자의 컴퓨터에서 동작합니다. 훅, CLI, MCP 서버는 네트워크 요청이나 텔레메트리를 보내지 않습니다. 세션별 이벤트 기록(각 프롬프트의 앞 500자, 실행한 명령, 바뀐 파일, 검사 결과, 탐지 결과)을 Claude Code의 플러그인 데이터 폴더에 저장하고 14일 뒤 삭제합니다. 비밀값은 기록하지 않습니다.

라이선스 확인

스토어 라이선스 키를 활성화할 때와 그 뒤 며칠마다, Veridone은 키, 스토어 조직 ID, 컴퓨터를 구분하는 무작위 이름, Veridone 버전, 운영체제 이름을 Polar의 라이선스 API로 보냅니다. 코드, 프롬프트, 파일에 관한 정보는 보내지 않습니다. 오프라인 키와 무료 체험은 전부 사용자의 컴퓨터에서만 확인합니다.

구매

주문은 판매 대행사인 Polar Software, Inc.가 처리하며, 결제·청구 정보는 Polar의 개인정보 처리방침에 따라 Polar가 받습니다. 판매자는 Polar로부터 이름, 이메일 주소, 국가, 주문 내역을 받아 라이선스 제공, 지원, 영수증 발행에만 사용합니다.

웹사이트

이 사이트는 GitHub Pages에서 제공되는 정적 사이트입니다. 쿠키, 방문 분석, 외부 스크립트나 외부 폰트를 쓰지 않습니다. 방문 기록은 GitHub 개인정보 보호정책에 따라 GitHub가 남길 수 있습니다.
